## 1. 产品概述

### 1.1 一句话定位

AI 商品套图是一项面向跨境电商商品设计的批量制图能力，用户提交同一商品的多张参考图片和中文卖点后，系统一次生成亚马逊主副图矩阵以及高级 A+、手机 A+ 套图。

### 1.2 用户问题

电商设计人员需要围绕同一商品分别制作卖点图、细节图、场景图和两种 A+ 图片，现有人工流程存在以下问题：

- 同一商品需要重复整理素材、卖点和图片参数；
- 主副图与 A+ 需要分别适配不同版式和尺寸；
- 批量生成过程中需要持续查看单图进度、失败项和费用；
- 生成结果还需要继续下载、返修、归档和恢复编辑。

### 1.3 产品目标

1. 通过一次配置完成同一商品整套电商图片的批量生成；
2. 在一个任务内统一管理主副图、A+、排版、模型及输出参数；
3. 支持逐图查看进度、处理失败项和局部返修；
4. 将结果与素材库、历史记录连接，形成可继续编辑的生产闭环。

### 1.4 成功判断

本版不编造业务 KPI。功能交付成功以以下可观察结果判断：

- 用户能够完成素材、卖点、类别、排版和模型参数配置并提交任务；
- 系统按照已启用类别和数量或排版规则生成目标图片；
- 用户能够处理成功、部分成功、失败和取消任务；
- 成功图片能够预览、下载、局部编辑和加入素材库；
- 任务结束后能够在历史记录中查看参数与结果，并继续编辑。

## 2. 用户与使用场景

### 2.1 目标用户

- 跨境电商设计人员；
- 需要批量制作商品主副图及 A+ 套图的运营人员；
- 负责查看组织生成任务的管理员。

### 2.2 核心使用场景

#### 场景 A：从商品素材生成完整套图

用户从素材库或本地上传同一商品的图片，填写中文卖点，选择目标图片类别、排版和生成参数，提交整套生成任务。

#### 场景 B：查看生成进度并处理结果

任务逐张完成后，用户无需等待整套结束，即可预览、下载、局部编辑或归档已完成图片；任务结束后可打包下载。

#### 场景 C：处理失败图片

任务部分图片生成失败或审核失败时，系统保留成功图片且不对失败图片扣费，用户只重试失败图片。

#### 场景 D：从历史任务继续编辑

用户进入历史记录查看任务参数、费用和分类结果，恢复原任务配置及结果后继续编辑。

## 5. 核心用户流程

### 5.1 主流程

1. 用户进入 AI 商品套图页面；
2. 用户从素材库选择或本地上传同一商品图片；
3. 用户调整图片顺序，确认第一张主商品图；
4. 用户填写中文商品卖点，可使用 AI 润色；
5. 用户选择上图语言；
6. 用户启用目标图片类别并设置数量；
7. 用户按需选择主副图排版和 A+ 排版；
8. 用户选择模型、主副图比例及清晰度；
9. 页面展示预计总张数和积分消耗；
10. 用户点击“一键生成整套”；
11. 系统校验必填项并提交后台任务；
12. 系统逐张更新生成进度和结果；
13. 用户对已完成单图进行预览、下载、局部编辑或加入素材库；
14. 任务结束后，用户可打包下载全部成功图片；
15. 系统创建历史记录，用户可从历史详情恢复完整任务继续编辑。

### 5.2 失败分支

- 单图生成失败：保留其他结果，用户可手动单独重试失败图片；
- 内容审核失败：标记审核失败，用户可手动重试；无自动重试、无申诉入口；
- 全部图片失败：任务标记失败，本次不扣费；
- 部分图片失败：任务标记部分成功，成功图片保持可操作；
- 网络中断或用户离开：后台任务继续，用户返回页面后恢复进度和结果。

### 5.3 取消分支

1. 用户在生成中点击取消；
2. 系统展示二次确认，说明已成功图片会保留；
3. 用户确认后，未完成图片停止继续生成；
4. 已成功图片继续可预览、下载、编辑和归档；
5. 任务状态记为已取消；
6. 任务结束后创建对应历史记录。

## 6. 功能详细需求

## 6.1 商品原图

### 6.1.1 输入规则

| 规则编号 | 规则 |
| --- | --- |
| R-INPUT-01 | 一次任务只允许使用同一商品的图片；首版由用户自行保证，系统不新增商品一致性识别与拦截能力 |
| R-INPUT-02 | 最多添加 16 张商品图片 |
| R-INPUT-03 | 第一张图片自动作为主商品图，其余为参考图 |
| R-INPUT-04 | 支持 JPG、JPEG、PNG，单张不超过 20MB |
| R-INPUT-05 | 非白底图允许上传，由系统自动抠图处理 |

### 6.1.2 添加方式

#### 素材库选择

- 支持从个人素材库和公共素材库选择；
- 支持关键词、类目和标签筛选；
- 弹窗中应展示当前已选数量及 16 张上限；
- 用户确认后，将本次选择追加到现有商品图列表；
- 与列表中已有素材重复时自动去重，不重复占用数量；
- 达到 16 张后不得继续加入新图片。

#### 本地上传

- 支持一次多选并追加；
- 上传后累计数量不得超过 16 张；
- 超出部分不加入列表，并提示用户仅保留上限内图片；
- 格式或大小不符合要求的图片不加入列表，并逐项说明原因；
- 合法图片不因同批次存在非法图片而被整体丢弃。

### 6.1.3 排序、替换、删除和预览

| 操作 | 处理规则 |
| --- | --- |
| 拖拽排序 | 列表顺序实时更新；排序后的第一张成为主图 |
| 替换 | 只替换当前位置；替换第一张后新图继续作为主图 |
| 删除普通图 | 仅删除当前图片，其余顺序保持 |
| 删除主图 | 删除后下一张自动前移成为主图 |
| 预览 | 打开大图灯箱，可在全部商品图间前后切换 |

### 6.1.4 状态

| 状态 | 页面表现 | 用户可执行操作 |
|---|---|---|
| 空状态 | 显示素材库选择和本地上传入口，数量为 0/16 | 添加图片 |
| 已添加 | 展示缩略图、文件名、主图标识及操作按钮 | 排序、预览、替换、删除、继续添加 |
| 已满 16 张 | 显示 16/16，新增入口不可继续加入 | 排序、预览、替换、删除 |
| 上传校验失败 | 保留合法图片，显示失败图片及原因 | 修正后重新上传 |

## 6.2 卖点文案与图片语言

### 6.2.1 卖点输入

| 规则编号 | 规则 |
| --- | --- |
| R-COPY-01 | 商品图和卖点文案均为生成前必填项 |
| R-COPY-02 | 卖点使用自由文本输入，最多 500 个中文字符 |
| R-COPY-03 | 系统识别逗号、换行和序号并自动拆分卖点 |
| R-COPY-04 | 用户统一输入中文 |
| R-COPY-05 | 系统按图片类别、排版容量和重要性自动分配卖点 |

- 输入为空时不得提交生成；
- 达到 500 个中文字符后不得继续输入；
- 卖点拆分只用于系统理解和分配，不改变输入框原文；
- AI 可优化表达，但不得改变商品卖点的事实含义。

### 6.2.2 AI 润色

1. 用户点击“AI 润色”；
2. 系统以浮层弹窗展示润色结果，头部左侧为“AI 卖点润色”标题、右侧标注“已完成”状态；
3. 浮层贴左侧配置栏顶部展开，仅在配置栏范围内叠加浅色遮罩，不覆盖右侧结果区与整页，不使用全屏深色蒙版；
4. 润色结果始终为中文（只优化“中文卖点”这一源头）；英语上图所需的英文在生成时按图片语言翻译，不在本弹窗展示；
5. 用户可点击“取消”关闭弹窗并保留原文；
6. 用户点击“确认”后，润色结果替换输入框内容；
7. 未经用户确认，不得自动覆盖原文。


### 6.2.3 图片语言

- 可选英语、中文；
- 默认英语；
- 英语模式：系统润色中文卖点并翻译为英语上图；
- 中文模式：系统润色中文并以中文上图；
- 无文字模式开启后，该项仍可编辑，因为 A+ 图片继续使用卖点文案。

## 6.3 图片类别与数量

### 6.3.1 类别

| 类别 | 分组 | 默认状态 | 默认数量 | 数量范围 | 输出尺寸/比例 |
|---|---|---|---:|---:|---|
| 卖点图 | 主副图 | 勾选 | 4 | 1～9 | 使用主副图比例及清晰度 |
| 细节特写图 | 主副图 | 勾选 | 4 | 1～9 | 使用主副图比例及清晰度 |
| 场景图 | 主副图 | 勾选 | 4 | 1～9 | 使用主副图比例及清晰度 |
| 高级 A+ | A+ | 勾选 | 4 | 1～9 | 固定 1464×600 px |
| 手机 A+ | A+ | 勾选 | 4 | 1～9 | 固定 600×450 px |


### 6.3.2 启用规则

- 取消勾选后，该类别不参与本次生成；
- 取消后数量步进器仍可调整，供再次启用时使用；
- 未选择任何类别时不得提交生成；
- 未手动选择排版时，五类全部启用且数量均为 9 时，整套最多生成 45 张。

### 6.3.3 数量来源优先级

1. 对某分组手动选择排版后，排版数量优先；
2. 主副图选择 N 个排版后，每个启用的主副图类别生成 N 张；
3. A+ 选择 N 个排版套系后，每个启用的 A+ 类别生成 N 张；
4. 手选排版后，对应分组的数量步进器禁用；
5. 未手选排版时，使用各类别数量步进器值。

## 6.4 排版选择

### 6.4.1 排版分组

- 主副图排版：卖点图、细节特写图、场景图共用；
- A+ 排版：高级 A+ 和手机 A+ 共用双尺寸模板套系；
- 两组排版分别选择，互不覆盖。

### 6.4.2 排版选择器

| 能力 | 规则 |
|---|---|
| 来源标签 | 平台推荐、我的、收藏 |
| 方向筛选 | 横版、方形、竖版 |
| 选择 | 点击卡片选中或取消；最多选择 8 个 |
| 清空 | 清除当前分组已选排版 |
| 收藏 | 收藏绑定当前账号并持久保存 |
| 收藏汇总 | 收藏标签实时汇总平台推荐和我的排版中的收藏 |
| 放大查看 | 打开排版灯箱查看完整图片、名称和方向 |
| 确认 | 保存当前选择并返回配置页 |


### 6.4.3 模板兼容规则

- 主副图模板按用途及目标比例筛选；
- A+ 模板按高级 A+、手机 A+ 固定尺寸适配；
- 与目标比例或固定尺寸不兼容的模板不可选；
- 不可选卡片需说明不兼容原因；
- 未手选排版时，系统根据商品主体、卖点、图片类别和目标比例选择官方模板。

### 6.4.4 我的排版

- 支持上传排版参考图；
- 参考图仅作为视觉参考，不解析成可编辑模板；
- 上传结果持久保存到当前账号“我的排版”；
- 支持常见图片格式（JPG、JPEG、PNG），单张不超过 10MB；
- 不限制“我的排版”上传数量。

### 6.4.5 平台推荐排版资源

- 平台推荐排版为正式内置资源，无历史存量数据；
- 排版素材由开发从 https://linkfox.ai/draw/product-image-suite 抓取，作为平台推荐排版素材来源（已确认）；
- 排版图仅用于展示与选择，交互规则同 §6.4.2。

## 6.5 模型与输出参数

### 6.5.1 模型

首版支持：

1. Nano Banana 2；
2. Wan 2.7 Image Pro；
3. Nano Banana Pro；
4. Seedream 5.0；
5. GPT Image 2。

- 模型由用户手动选择；
- 页面默认选中 Nano Banana 2；
- 五个模型必须支持本页面相同的输入参数和能力；
- 模型能力描述用于辅助选择，不得承诺未验证的成功率或生成效果。

模型选择器为浮层下拉，头部展示"选择模型"标题与"5 个选项"计数；每张模型卡展示模型图标、名称、能力描述，右上角展示该模型的预计速度标签，当前选中卡展示"已选"标记。速度标签为**单个模型的预计生成速度提示**，仅用于辅助模型选择，与"不展示整套预计耗时"的规则不冲突；标签数值由平台模型配置动态下发、按实际展示（原型中 Nano Banana 2、Wan 2.7 Image Pro、Nano Banana Pro、Seedream 5.0、GPT Image 2 所示秒数均为占位示例），前端不写死任何秒数。


### 6.5.2 主副图比例

可选：

- 智能比例；
- 1:1；
- 3:2；
- 2:3；
- 16:9；
- 4:3；
- 3:4；
- 9:16。

规则：

- 比例统一作用于卖点图、细节特写图和场景图；
- 智能比例综合排版方向、商品主体形态和图片类别确定最终比例；
- A+ 使用固定尺寸，不受主副图比例影响；
- 当前原型默认 1:1。


### 6.5.3 清晰度

- 可选 1K、2K、4K；
- 当前原型默认 2K；
- 表示主副图输出最长边像素档位，另一边按比例计算；
- 1K/2K/4K 沿用平台现有清晰度规则，本模块不重新定义精确像素映射与取整规则；
- 高级 A+、手机 A+ 使用固定尺寸，不受清晰度影响；
- “高画质”为固定生成标准，不增加独立选择项。


### 6.5.4 无文字模式

- 默认关闭；
- 只影响卖点图、细节特写图和场景图；
- 开启后上述三类图片不生成上图文字；
- 不影响高级 A+ 和手机 A+；
- 卖点输入和图片语言继续保持可编辑。


### 6.5.5 预计信息

页面常驻展示：

- 预计生成总张数；
- 预计积分消耗。

预计生成总张数随数量配置变化同步更新。本功能积分按功能固定计费（每次 8 积分，与张数无关，见第 7 章），预计积分恒为 8 积分，不在前端写死其他演示数值。本功能不展示预计耗时。

## 6.6 提交生成

### 6.6.1 提交前校验

| 校验项 | 不满足时处理 |
|---|---|
| 至少有 1 张商品图 | 不提交任务，提示先添加商品图 |
| 卖点文案非空且不超过 500 字 | 不提交任务，提示填写或缩短卖点 |
| 至少启用 1 个图片类别 | 不提交任务，提示选择生成类别 |
| 数量或排版选择合法 | 不提交任务，定位到对应配置项 |
| 模型、比例和清晰度已选择 | 使用页面当前选中值；不得为空 |

### 6.6.2 提交行为

- 点击“一键生成整套”后直接提交，不增加确认弹窗；
- 提交成功后按钮切换为不可重复点击的生成中状态；
- 页面展示已完成张数/总张数；
- 系统按目标图片逐张生成并更新结果；
- 任务在后台持续运行，用户离开或刷新不终止任务；
- 用户返回页面后恢复任务进度和已完成结果。


### 6.6.3 防重复提交

生成按钮在提交中及生成中不可重复触发，用于避免同一配置产生重复任务。本规则是落实现有生成中禁用状态所必需的交互约束，不新增独立功能。

## 6.7 任务状态

### 6.7.1 任务状态定义

下表”枚举标识”为供前后端统一的机器可读值（已确认）。

| 状态 | 枚举标识 | 进入条件 | 页面表现 | 用户可执行操作 | 退出条件 |
|---|---|---|---|---|---|
| 待配置 | `DRAFT` | 尚未提交任务 | 显示配置区和结果空状态 | 编辑配置、生成、清空 | 提交任务 |
| 提交中 | `SUBMITTING` | 用户点击生成，系统正在创建任务 | 生成按钮禁用，显示提交反馈 | 等待 | 创建成功或失败 |
| 生成中 | `GENERATING` | 任务已创建且存在未完成图片 | 显示完成数/总数及逐图状态 | 查看已完成图、取消任务 | 全部结束或取消 |
| 成功 | `SUCCESS` | 所有目标图片生成成功 | 显示全部结果与打包下载 | 预览、下载、编辑、加素材、继续编辑 | 用户发起后续操作 |
| 部分成功 | `PARTIAL_SUCCESS` | 至少一张成功且至少一张失败或审核失败 | 同时展示成功与失败项 | 操作成功图、重试失败图、打包成功图 | 重试后重新结算状态 |
| 失败 | `FAILED` | 无成功图且目标图片全部失败 | 展示失败原因及失败项 | 重试失败图 | 重试后进入生成中 |
| 已取消 | `CANCELLED` | 用户确认取消 | 保留成功图，未完成项停止 | 操作成功图 | 用户离开或继续处理结果 |

### 6.7.2 单图状态

单图状态沿用平台现有枚举，本模块不做重新定义：

| 状态 | 页面表现 | 计费 |
|---|---|---|
| 排队中 | 占位卡片及等待状态 | 整套一口价，单图不单独计费 |
| 生成中 | 单图进度反馈 | 整套一口价，单图不单独计费 |
| 已完成 | 展示完整结果及操作按钮 | 计入整套 8 积分，不单独计费 |
| 生成失败 | 展示失败原因和重试入口 | 不单独计费 |
| 已终止 | 未完成图片停止生成 | 不单独计费 |

整套计费以任务是否产生成功图片为准：任务至少 1 张成功即按 8 积分计费一次，全部失败或无成功图片则不扣费。

### 6.7.3 取消规则

- 生成中提供取消入口；
- 取消前展示二次确认；
- 二次确认需明确“已成功图片将保留，未完成图片将停止”；
- 取消后任务状态为已取消，不改记为部分成功；
- 已成功图片保留全部结果操作；
- 取消前已有成功图片时按整套 8 积分计费一次，无成功图片则不扣费。

## 6.8 生成结果

### 6.8.1 结果分组

- 结果按卖点图、细节特写图、场景图、高级 A+、手机 A+ 分类；

### 6.8.2 单图操作

### 6.8.4 打包下载

- 无成功图片时不提供打包下载。

## 6.9 局部编辑

### 6.9.1 入口与步骤

1. 用户在成功图片上点击“局部编辑”；
2. 编辑器载入当前图片；
3. 用户使用画笔或框选工具标记重绘区域；
4. 用户可调整画笔粗细、撤销或清空选区；
5. 用户填写局部修改提示词；
6. 用户点击重新生成；
7. 系统生成 1 张候选图；
8. 用户对比原图和编辑后结果；
9. 用户可重新生成或应用替换；
10. 应用后替换任务中的当前图片，原图继续保留并可恢复。

### 6.9.2 编辑规则

| 规则编号 | 规则 |

| R-EDIT-01 | 沿用原图模型、尺寸和排版 |
| R-EDIT-02 | 只重绘选区，其他区域保持不变 |
| R-EDIT-03 | 每次只生成 1 张候选 |
| R-EDIT-04 | 重新生成后旧候选不保留 |
| R-EDIT-05 | 应用后替换任务对应图片，同时保留原图 |
| R-EDIT-06 | 支持一键恢复原图 |
| R-EDIT-07 | 成功生成候选图后单独扣费，失败不扣费 |

### 6.9.3 编辑状态

| 状态 | 页面表现 | 用户操作 |
|---|---|---|
| 未选区 | 显示原图，生成操作不可用 | 画笔或框选 |

| 生成中 | 锁定重复生成操作 | 等待 |
| 生成成功 | 展示原图/候选图对比 | 重新生成、应用替换 |
| 生成失败 | 保留原图和选区，展示失败提示 | 修改提示词后重试 |
| 已应用 | 结果卡片更新为新图，原图进入可恢复状态 | 下载、继续编辑、恢复原图 |

### 6.12.2 清空范围

## 7. 计费规则

### 7.1 整套生成计费

- 积分按功能计费，不按图片张数、模型或清晰度分档：每次"一键生成整套"固定 **8 积分**，与本次生成张数无关；
- 页面提交前展示预计积分消耗，即固定 8 积分；
- 只要任务至少成功生成 1 张图片，即按 8 积分计费一次；
- 全部图片失败、无任何成功图片时，本次不扣费；
- 用户取消后，若取消前已有成功图片，按 8 积分计费一次；无任何成功图片则不扣费；
- 内容审核失败等同于生成失败，不单独扣费。

### 7.2 失败重试

- 只重试失败或审核失败的图片；
- 重试属于原任务的后续处理，不新建独立历史记录；
- 重试期间原历史记录状态更新为生成中，原成功结果继续保留；
- 重试结束后，在原记录中更新最终任务状态、失败项和成功结果；
- 整套按功能计费一次，重试不重复扣费；若首次提交因全部失败未计费，重试后产生首张成功图片时按 8 积分计费一次。

### 7.3 局部编辑

- 局部编辑属于独立于整套生成的操作，按平台对应功能规则单独计费；
- 每次成功生成候选图计费一次，生成失败不扣费；
- 用户生成候选后不应用替换，仍属于成功生成结果并计费。

### 7.4 计费说明

- 本功能按功能计费，每次"一键生成整套"固定 8 积分，不区分张数、模型与清晰度；
- 预计耗时不在本功能展示。

## 13. 范围小结

- 功能链路：商品图、卖点文案、图片类别与数量、排版、模型与参数、提交与任务状态、生成结果、局部编辑、素材库联动、历史记录、清空，均已覆盖；
- 任务状态：成功、部分成功、失败、审核失败、取消和恢复均已定义；
- 计费：整套按功能固定 8 积分/次，全部失败不扣费，局部编辑按对应功能单独计费；
- 清晰度沿用平台现有规则，本功能不展示预计耗时；
- 失败与审核失败仅支持手动重试，无自动重试与申诉；历史记录长期保存，本功能为新增、无存量任务需兼容；
- 验收标准覆盖正常、边界、异常、权限和联动场景。
