先马 AI 设计平台 — 产品规划方案（2026 下半年）

整理人：梦蝶 整理时间：2026-06-28 文档性质：产品规划 · 内部讨论稿 基于：新戈 v3.0 原方案 + 下半年落地计划补充

一、产品概述

1.1 产品定位

打造先马电商团队的内部 AI 视觉生产平台：以效率提升和品牌标准管控为核心目标，整合国内主流 AI 图片/视频生成模型，服务设计部门和运营部门的日常视觉内容生产需求，提供从素材生成、设计排版、平台适配、AI 评审到一键发布的全流程设计服务，将生成结果沉淀为可复用的团队素材资产，逐步减少对外部工具和外包的依赖。

1.2 核心价值

价值说明
降本增效设计/运营日常出图效率提升 3-5 倍，减少重复性精修和改图工时
品牌管控内置先马品牌标准，AI 评审引擎自动筛查不合规内容，减少人工审图
场景化零门槛针对先马主营品类（大护具等穿戴式护具）定制场景模板，普通运营无需提示词也能一键生成
素材沉淀历史记录 + 素材库打通，生成结果自动归档，形成可复用团队视觉资产
数据安全商品图、品牌素材在内部平台流转，明确第三方模型数据传输边界
全链路素材生成 → 设计排版 → 平台适配 → AI 评审 → 一键发布
双模式标准模式（场景化一键生成）+ 自助模式（专业自定义），同一页面内切换
内容配套图片 + 评论 + 文案一站式产出，运营可独立完成图文内容组合

1.3 目标用户

用户类型使用场景核心需求
普通运营/客服日常图片修改、买家秀生成、基础海报零门槛、一键生成、场景化
专业设计师商品主图、详情页、品牌海报高阶能力、自定义、批量处理
内容运营多平台内容发布、标准评审、素材沉淀标准管控、AI 评审、数据资产

1.4 平台当前现状

  • 已有高频功能入口：一键改字、主体替换、产品微调、批量美颜、AI 买家秀、AI 提示词、AI 多角度、AI 区域重绘
  • 已形成基础闭环：素材库、历史记录、结果预览、结果下载、历史继续编辑、单图/整条加入素材库、积分展示、模型切换
  • 历史记录已支持我的记录/所有记录、日期筛选、功能筛选、复制提示词、查看详情、继续编辑、整条加入素材库
  • 素材库已支持个人/公共素材库、上传素材、类目筛选、标签筛选、来源筛选
  • 视频能力已有实验性入口，但稳定性和闭环不完整
  • 无限画布 V1.0 开发中，保存草稿和导出功能暂未开放
  • 内部测试用户约 600 人，核心用户约 200 人（设计部门 + 运营部门）

三、核心功能模块

3.1 模型集成引擎

集成国内主流图片/视频生成模型，统一接入，统一调用。

类型说明
图片生成文生图、图生图、参考图生成
视频生成文生视频、图生视频、视频编辑
多模态图文理解、视频理解

模型调度策略：

  • 多模型智能调度，根据场景选择最优模型
  • 模型能力互补，支持模型组合使用
  • 模型版本管理，支持升级和回滚
具体模型选型和成本对比，需技术对齐时确认。

3.2 双模式设计引擎

每个功能模块提供两种模式，满足不同用户需求。

标准模式（场景化一键生成）
场景化封装按场景预设完整设计流程
零提示词用户无需编写提示词，选择场景即可
一键生成选择场景 → 上传素材 → 一键生成
适用人群普通运营、客服

自助模式（专业自定义）
参数自定义提示词、风格、尺寸、比例等自由调整
参考图模式上传参考图，AI 参考生成
高级控制支持高级参数调节
适用人群专业设计师

3.3 场景化生图模块（电商套图）

按电商场景打包生成整套图片：主图、场景图、卖点图、细节图、多角度图等，一次生成 3-5 张套图，支持批量生成。

标准模式：选择品类 → 一键生成完整套图
自助模式：自定义参数 → 灵活调整每张图

3.4 自助生图 + 提示词模板库

专业设计师自由创作入口，支持完整参数控制（提示词、风格、尺寸、比例、模型选择、参考图角色等）。设计师调好的参数可沉淀为模板，运营和客服直接复用，降低使用门槛。

3.5 垂直场景模块

按垂直场景开发专项生图功能，每个场景对应一套完整的设计流程。先搭建通用垂直场景框架，再按平台逐个铺开。

平台说明计划
买家秀模拟真实买家秀图片，场景模板 + 批量生成9月
淘宝主图/详情页尺寸规范，商品图风格9月（复用买家秀框架）
小红书3:4 比例、封面图、种草风格11月
天猫品牌旗舰店规范，主图/详情页标准11月（复用框架）
抖音封面图、短视频封面、带货风12月
跨境亚马逊/速卖通常用尺寸和风格12月
私域朋友圈配图、社群海报、公众号封面12月

3.6 AI 图片评审引擎

AI 根据企业内置标准评审生成的图片，确保输出质量。

评审流程：

AI 生成图片 → 多维度评分 → 符合标准？
                              ├─ 是 → 通过 → 发布/下载
                              └─ 否 → 重新生成 → 再次评审
维度评审内容权重
图片质量清晰度、构图、色彩、光影30%
品牌一致性Logo 使用、色调、风格统一性25%
平台规范尺寸、比例、内容合规性25%
营销效果吸引力、信息传达20%

企业标准库：企业可自定义评审标准，支持多品牌/多产品线管理，标准可配置、可迭代。

3.7 AI 营销文案生成

根据生成的图片自动书写营销文案，文案与图片内容匹配。

能力说明
图片理解AI 理解图片内容、风格
文案生成根据图片自动生成匹配文案
多平台适配小红书种草风、抖音带货风、天猫促销风
二次创作支持文案修改、风格切换、多版本生成

场景文案类型平台风格
商品主图产品卖点文案天猫/抖音带货风
买家秀种草文案小红书种草风
海报/Banner促销文案全平台适配
社交媒体配图互动文案小红书/朋友圈风

3.8 AI 评论生成

基于商品信息、卖点和使用场景，生成多条买家口吻评论，支持数量、语气风格选择和复制使用。与营销文案生成共用底层能力。

3.9 视频生成与切片

视频生成：文生视频、图生视频，覆盖产品短视频和种草内容。
视频切片：上传视频 → 关键帧提取 → 场景识别 → 素材分流（图片/视频片段分类）→ 生成主图、海报素材、GIF 等。

场景输入输出
产品视频拆解产品宣传视频商品主图、卖点图
宣传视频拆解品牌宣传视频海报素材、Banner 素材
动态内容生成产品视频GIF 动图、短视频片段

3.10 无限画布

专业设计模块，支持画布自由编排、节点连接、多素材组合。设计师可在画布上灵活组合生成结果，进行二次创作。

3.11 一键发布（待确认）

针对小红书、抖音等平台，实现从生成到发布的全链路。需提前调研各平台 API 开放情况和账号授权可行性。如果接口不支持，降级为"发布包导出"（将图片、标题、正文、标签打包，人工发布）。

7月 — 地基月

不动新功能，把平台基础设施理顺。

IA 重组背景：当前平台功能已基本覆盖，但入口分散、归属模糊，用户路径不够清晰。前期为快速响应需求，功能持续叠加，导致页面布局偏散、UI 也不够统一。现在需要从产品侧牵头，做一次系统性的梳理。不只是体验优化，更直接影响下半年场景化的推进 —— 功能组织不理顺，场景模块就找不到清晰的承载位置。趁现在体量不大，7 月是理顺 IA 的最佳时期，等新功能叠加后再做优化成本会成倍增加。因此 7 月主线是先搭架子：导航体系、布局结构、交互流统一，及日常业务部门的零散需求。

优先级事项说明
P0IA 重组导航/入口统一整理，归拢创作中心
P0测试环境 + 发布流程 + 回滚开发不直接上生产
P0积分扣费规则确认扣多少、失败退不退
P0核心链路稳定性排查改字/替换/微调/买家秀报错率

五、项目风险

5.1 项目级风险

风险影响需要谁参与建议应对
团队资源被分流下半年计划依赖团队持续投入，如果被其他项目分流，整体交付顺延管理层会上明确下半年资源投入范围和优先级
一键发布依赖外部平台小红书/抖音 API 是否开放、账号授权是否可行、发布结果能否回传、平台审核规则是否影响发布，都不是产品侧能单独决定业务 + 研发先做可行性调研，再决定是"一键发布"还是"发布包导出"
外部 AI 模型供应商依赖核心能力依赖第三方模型，存在模型不可用、成本上涨、供应商策略变化、数据合规等风险研发 + 管理层确认可用的模型供应商范围、数据安全边界，建立备用模型切换机制
AI 评审标准不明确品牌标准、评分维度、达标口径需要设计团队/管理层共同制定，产品侧无法独立定义设计团队 + 管理层会前先拉设计对齐初版标准，会上确认
数据安全与素材合规商品图、品牌素材、模特图通过第三方模型处理时，需要明确数据传输边界和可用模型范围管理层 + 研发明确哪些素材可以走外部模型、哪些只能内部处理

六、效果衡量体系

6.1 为什么建

建指标体系就一个目的：用数据体现出平台和团队的价值。具体落到三个层面——

  • 平台价值：到底帮业务省了多少时间、提了多少效率
  • AI 战队价值：我们做的事有没有产生实际效果
  • 效率与成本数据：投入了多少，产出了多少

同时，这套数据也是明年方向的依据——通过数据说明哪些做得好、哪些不行，后续怎么迭代优化。

6.2 关注哪些指标

维度指标为什么看这个
使用情况目标用户渗透率目标用户里实际有多少人在用？没用的卡在哪？
周活跃复用率用一次就扔还是变成日常工具？
效率提升单任务耗时对比做一张主图以前多久、现在多久？提效最硬的证据
