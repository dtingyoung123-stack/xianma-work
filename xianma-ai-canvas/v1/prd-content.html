先马 AI 无限画布 V1.0 PRD

更新时间：2026-07-08 产品定位：以图片创作为核心的无限画布工作台 交互参考：Liblib / RunningHub
本文档面向设计与开发，目标是把当前 PRD 变成更适合评审的 HTML 版：左侧目录 + 右侧阅读主文档 + 重点 callout + 表格化状态，方便快速定位功能、状态和默认值。
01

项目背景

先马 AI 设计平台当前的图片能力分散在多个工具页中。设计师在多轮创作时，需要频繁切换页面、重复上传、重复填写参数，难以围绕同一张图片持续加工，也不利于结果沉淀和复用。

无限画布 V1.0 的目标不是做成完整工作流平台，而是先搭建一个可用的图片创作工作台，让设计师围绕项目，在单画布中完成图片输入、续作生成、结果回流、历史沉淀、素材复用和下载结果的完整闭环。

02

版本目标

V1.0 重点解决的问题
  • 支持多项目管理，便于设计师区分不同创作任务。
  • 每个项目内先按单画布处理，避免首版复杂度失控。
  • 支持图片节点进入画布并围绕节点进行就地生成。
  • 支持 5 个现有 AI 图片工具挂接到画布中。
  • 支持结果回流到画布并进入历史记录。
  • 支持结果加入素材库和下载图片。
  • 支持节点右侧 + 先弹出四项菜单，再进入素材 / 历史 / 上传 / 提示词。

核心链路：项目管理页 → 新建/进入项目 → 图片进入画布 → 选择 AI 工具 → 节点内配置参数 → 生成 → 结果回流 → 历史沉淀 → 加入素材库 / 下载图片。

04

目标用户与场景

核心用户

设计师

典型使用场景
  1. 把商品图、参考图或历史结果拉入画布，围绕同一张图做连续加工。
  2. 在节点上切换 AI 工具，快速比较不同版本的结果。
  3. 将可复用结果沉淀到素材库，后续继续回流到画布。
  4. 对局部区域重绘、主体替换、商品精修或多角度生成。

08

详细功能说明

8.1 项目管理页

承接无限画布的上一级入口，负责统一管理项目和文件夹。

  • 查看项目列表
  • 新建项目
  • 新建文件夹
  • 项目重命名 / 移动 / 删除
  • 文件夹重命名 / 删除
  • 点击项目进入无限画布
8.2 无限画布主页面

承接项目内图片创作，围绕单画布完成输入、加工、结果回流与资产沉淀。

  • 顶部：项目名、保存画布、下载结果、生成、撤销、重做、适应画布
  • 左侧：添加、素材、历史、工具
  • 中间：画布、节点、连线、小地图、缩放
  • 节点下方：提示词输入、模型、参数设置、张数、生成按钮
8.3 节点类型与规则

图片节点

  • 图片节点是画布的核心节点类型。
  • 图片可来自本地上传、素材库、历史结果、生成结果。
  • 节点本身按“图片节点”统一表达，不按来源拆分类型。
  • 图片节点统一固定比例展示，不按原始尺寸硬撑节点。
  • 空节点可先上传图片或直接生成，图片回填到同一个节点上。
状态展示
空节点仅显示占位和可操作入口
可编辑节点存在图片且可继续加工
排队中显示排队中标签
处理中显示处理中标签
成功显示绿色成功标签
失败显示失败标签

提示词节点

提示词节点用于记录提示词和创作说明，不强制具备图片工具，主要用于创作输入。

8.4 节点右侧 + 续作入口

节点右侧 + 用于围绕当前节点继续添加输入或建立连接。

  1. 点击 + 先展示四项菜单：上传图片、从素材添加、从历史添加、新增提示词。
  2. 按住 + 拖拽时，作为连线动作使用。
  3. 从已有节点 + 进入素材/历史后，选择的内容应作为子节点并保留连线。
  4. 左侧素材库 / 历史记录直接“加入画布”时，只创建独立节点，不强制连线。
  5. 选择“上传图片”后，仅打开上传弹窗；只有图片上传成功后才创建节点。
8.5 左侧添加 / 素材 / 历史 / 工具

添加

只负责补输入，包括上传图片、从素材加入、从历史加入、新增提示词。

素材

浏览素材库，支持搜索、筛选、查看详情、加入画布。

历史

浏览历史结果，支持查看参数、加入画布、下载图片。

工具

只对当前选中图片节点生效，不和左侧添加入口重复。

8.6 节点上方工具条

图片节点被选中后，节点上方显示小工具条，参考竞品以图标 + 工具名方式呈现。

  • 只在当前选中节点上显示。
  • 点击画布空白区域后关闭。
  • 点击其他节点后切换到新节点上方显示。
  • 图标化展示，避免纯单字按钮。
  • 工具名可见，不需要单独重复说明文案。

包含工具：一键改字、主体替换、产品微调、AI 区域重绘、AI 多角度、下载图片。

8.7 节点下方生成设置

节点下方承载生成设置，是“选区编辑 / 主体参考”等前置动作之后的执行层。

  • 固定内容：提示词输入框、模型选择、参数设置、选择张数、生成按钮。
  • 节点下方不再展示冗余的纵向表单堆叠。
  • 点击其他空白区域时，参数浮层自动关闭。
  • 点击输入框、模型、参数、张数、生成按钮时，生成设置保持展开。
  • 多张结果时不要直接铺满画布，使用结果组节点承载。
8.8 结果组节点

当一次生成返回多张图片时，不直接铺出多个节点，而是生成一个结果组节点。

  • 默认只显示一张主图和数量胶囊。
  • 点击数量胶囊后，展开候选缩略图抽屉。
  • 可左右切换查看不同结果。
  • 默认继续编辑 / 加入素材库 / 下载图片作用于当前选中结果。
  • 基于某一张结果继续生成时，结果组节点仍可作为上游节点。
8.9 - 8.13 五个 AI 工具

一键改字

替换图片中文字并尽量保持原图版式和商品质感。默认模型 GPT Image 2，张数 1 张。

主体替换

替换当前图片中的目标主体，如模特、商品、局部主体等。上传主体参考图后，只在节点内展示参考缩略图，多张支持左右切换。

产品微调

对当前商品图进行精修和商业质感优化。优化方向放在生成设置上方，四项一排展示：精修、质感、商品化、可控修改。

AI 区域重绘

针对图片局部区域重新绘制，适合修复瑕疵、局部改动和扩图前置。点击“区域重绘”会打开深色大弹层选区编辑器，应用选区后回到节点继续生成。

AI 多角度

基于同一主体生成不同角度视图，提供正面、背面、左侧、右侧、左前 45°、右前 45°、左后 45°、右后 45° 等角度包。

8.14 更换图片

图片节点可直接替换当前节点图片。

  • 点击“替换”后直接打开系统文件选择器。
  • 支持从桌面拖拽图片进入画布。
  • 拖到已有图片节点上时，直接替换该节点。
  • 拖到空白处时，新增图片节点。
  • 替换只更新当前节点内容，不影响连线和节点位置。
8.15 历史记录与素材库

历史记录

  • 展示历史任务
  • 可查看参数
  • 可加入画布
  • 可下载图片
  • 多张结果可进入历史

素材库

  • 展示个人素材和公共素材
  • 可搜索、筛选和加入画布
  • 进入画布后作为图片节点使用

11

文案规范

  • 产品整体文案风格：简洁直接、以设计师可操作为主、少解释多动作、失败提示说明原因 + 给出下一步。
  • 关键文案：未选中图片节点「请先选择图片节点」；区域重绘未应用选区「请先应用选区」；主体替换未上传参考图「请先上传主体参考图」；上传成功「图片已替换」；生成成功「生成成功，结果已回流到画布」。
12

非功能性需求

执行约束
  • 首屏加载应保证画布可交互优先。
  • 节点拖拽、缩放、选择、连线应保持流畅。
  • 错误提示应明确，不可只显示“失败”。
  • 图片上传、替换、生成结果、历史下载都应保留基础失败兜底。
  • 画布需要支持较大数量节点的可视化，不应因多张结果直接铺开导致拥挤。
