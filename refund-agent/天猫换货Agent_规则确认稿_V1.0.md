## 2. 自动换货条件（同意换货）

SOP 上线标准：退货物流显示【发往长沙】即可操作换货。

| 规则 | 自动换货条件 | 不满足时 |
|---|---|---|
| 售后类型与状态 | 天猫换货售后，订单状态为待收货/交易成功 | 非换货类型跳过；已完结不重复操作 |
| 退货物流方向 | 退货物流轨迹出现“长沙”（发往/到达长沙均可） | 未出现“长沙”时进入拒绝/转人工/等待分支（见第 4 节） |
| 必要信息 | 售后单号（退款编号）、订单号、换货尺码、件数、物流单号、物流轨迹、平台倒计时可可靠读取 | 信息缺失或无法识别时转人工，不猜测 |
| 执行前复核 | 生成换货单前重新读取物流状态，仍明确显示发往长沙 | 状态变化时停止自动化并按最新状态处理 |

- 物流口径已确认（B1）：退货物流轨迹出现“长沙”字段即视为发往长沙，无需等待签收或入库，与退款场景口径一致。

## 3. 操作步骤（自动执行链路）

以下为 SOP 原文步骤整理为 Agent 可执行链路：

1. **平台定位**：天猫商家后台 → 左侧【交易】→ 退款管理 → 待处理售后【全部】→ 按“换货”筛选，查看售后单及退货物流是否发往长沙。
2. **生成换货单**：物流已发往长沙 → OMS 系统 → 订单管理 → 换货申请 → 搜索交易号 → 选择 → 生成换货订单 → 确定。
3. **核对与配货**：OMS 搜索订单号 → 查看换货尺码是否与平台申请一致 → 不一致时点击【修改商品】修正 → 结算金额修改为 **0** → 手工配货（配货可感知产品是否缺货）。
4. **平台标记**：返回平台 →
   - 配货成功订单：插旗备注“已换出 + 日期 + 工号”；
   - 缺货订单：留言缺货话术，插旗备注“缺货引导退款 + 时间”。

已确认（C1）：OMS 生成换货订单即视为平台侧同意换货，无需在平台单独点击“同意换货”按钮。

## 4. 判断规则（决策表）

SOP 判断规则整理为四类动作，优先级已确认（B7）：**转人工硬条件 > 地址不一致 > 拒绝(临期) > 同意/等待**；同一售后命中多条规则时，转人工与拒绝优先，不执行同意。

| 动作 | 触发条件 | Agent 动作 |
|---|---|---|
| **同意换货** | 退货物流轨迹显示“长沙”，未命中任何转人工/拒绝条件 | 执行第 3 节完整链路（生成换货单 → 核对尺码 → 改金额 0 → 手工配货 → 插旗） |
| **拒绝换货** | 退货申请倒计时 < 48 小时，退货物流依旧未显示到长沙 | 留言拒绝申请话术并点击“拒绝换货”按钮 |
| **协商退款** | 买家换货物流异常 | 留言协商/提醒话术并转人工（已确认 B6：V1 不自动发起平台协商退款） |
| **转人工** | ① 退货物流签收地与退货地址不一致<br>② 订单商品件数 > 10 件<br>③ 上传单号后超 3 天无物流更新<br>④ 换货件数为 2、需拆分发货订单<br>⑤ 平台报错、原因不明<br>⑥ 客服备注需换货其他商品/修改换货件数<br>⑦ 信息缺失、冲突或结果不明确 | 按场景留言对应话术（如有）并转人工，停止自动操作 |

## 5. 时效规则

| 节点 | 时效 | 说明 |
|---|---|---|
| 换货时效 | 10 天 | 买家寄回后、待商家收货时效为 10 天 |
| 换新商品发货 | 包裹签收后 2 天内发货 | 仓库执行发货；Agent 不跟踪（已确认 D3） |
| 拒绝节点 | 倒计时 < 48 小时 | 物流未到长沙时自动拒绝 |
| 物流无更新节点 | 上传单号后超 3 天 | 留言并转人工 |
| 扫描频率 | 每 30 分钟 | 已确认（D2）：沿用退款场景每 30 分钟扫描、按临期从短到长 |

## 6. 完成及异常判断

- **成功判定**：配货正常即换货成功（生成换货单并配货成功，插旗备注完成）。
- **异常处理**：
  - 换货件数为 2，需拆分发货订单 → 转人工；
  - 平台报错、不明原因 → 转人工；
  - 订单有客服备注需换货其他商品/修改换货件数 → 转人工；
  - 操作结果不明确（点击后无法确认成功/失败）→ 禁止重复操作，转人工核验；
  - 登录失效、验证码、页面改版、按钮缺失 → 停止自动处理并转人工。

2. **买家退货物流异地签收**：亲亲，您上传的退货快递单号显示在其他地址签收，我们的退货仓在湖南长沙哦，辛苦您尽快核对下快递单号是否填错了，避免耽误您的退货申请，核对后可联系店铺人工客服提供正确退回单号哦
3. **拒绝申请**：亲亲，商品退回后才可退款哦，目前您的退货物流存在异常，小店未收到您退回的产品，退款即将超时暂时拒绝您的申请，后续找到正确单号了您重新申请一下或者联系人工客服处理哦
4. **换货缺货**：亲，实在不好意思，我们在给您质检出库时，发现产品有一点点小瑕疵，我们也知道您购买宝贝也是看中质量问题，所以避免您收到会有此问题，我们这边决定全部退回返厂，重新制作！保证好质量 先给您处理退款可以嘛

## 9. 上线风险与控制

- 自动换货涉及 OMS 生成换货单、改金额、手工配货、插旗等真实业务操作，需业务知晓：AI 无法保证 100% 准确，页面变化、信息识别错误、物流更新延迟、人工同时操作或平台/OMS 异常，都可能导致误操作、重复操作或漏处理。
- 同一店铺、同一售后单号只能执行一次自动换货链路；重复扫描、并发执行、网络超时和进程重启不得造成重复生成换货单。
- 每次判断保存字段值、命中规则、操作时间和操作前后证据；订单号、售后单号、物流单号、金额、地址和手机号不得出现在公开材料中。
- 出现误操作、重复操作、平台风控或页面规则失效时，应立即暂停受影响店铺或场景。
- 自动化只能降低人工处理成本和超时风险，不能完全消除操作风险，异常情况必须由人工接管。
