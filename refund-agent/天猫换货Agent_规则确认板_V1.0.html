自动换货条件

  • 退货物流轨迹出现“长沙”（发往/到达长沙）即可操作换货，无需等待签收。
  • 物流口径已确认（B1）：轨迹出现“长沙”字段即视为发往长沙，无需等待签收。
  • 信息缺失、冲突或结果不明确时转人工，不猜测。

  • OMS：生成换货订单、修改商品/尺码、结算金额改 0、手工配货。

成功判定

配货正常即换货成功。换新商品发货由仓库执行（包裹签收后 2 天内发货），Agent 不跟踪发货（D3 已确认）。

异常处理

  • 换货件数为 2、需拆分发货订单 → 转人工
  • 平台报错、不明原因 → 转人工
  • 客服备注需换货其他商品 / 修改换货件数 → 转人工
  • 操作结果不明确 → 禁止重复操作，转人工核验

触发条件与风控边界

触发条件

SOP 原文：“跟上线标准、判断规则一致”。即：扫描到换货类型售后即进入判断，物流显示长沙即操作，未显示按临期/停滞规则分流。

风控边界

SOP 原文：“与上线标准、触发条件、判断规则”，表述不完整；边界以本板判断规则为准（E2 已确认）。

唯一标识

售后单号（退款编号）为唯一标识；同一订单可能存在多个产品（多售后单），须按售后单维度处理并防重复。
