# V2.1.0 本地文件自动化 MVP 原型说明

> 状态：静态原型已实现，待用户验收  
> 产品版本：V2.1.0  
> 实现边界：仅验证入口、授权、执行状态和结果交互，不读取真实文件，不调用真实模型，不控制 Office/WPS。

## 一、目标

用最小范围验证“员工在主对话中说明本地文件任务，经明确授权后得到新文件和可追溯结果”的闭环。首期价值集中在减少固定表格转填、文档整理和提纲制作为演示文稿的重复操作，同时保留原件、异常和授权证据。

## 二、入口

- 自然语言：在“新对话”描述 Excel、Word 或 PPT 的本地处理任务。
- 显式工具：选择 `/本地文件` 后补充任务描述。
- 建议项：点击“处理本地 Excel、Word 或 PPT”进入同一主对话并预置工具。
- 只有附件或只有命令时留在原页追问，不创建任务。

## 三、演示流程

### Excel 完整流程

固定演示文件为 `新品资料.xlsx` 和 `新品登记模板.xlsx`，输出为 `新品登记表_处理后.xlsx`。流程覆盖工作区授权、执行计划、格式与字段校验、固定映射、生成新文件、逐项校验、正常/异常结果、同名文件保存副本与覆盖二次确认。

### Word 简化流程

读取 `新品上市资料.docx` 的标题、正文第 1-12 段，经单次内容授权后生成 `新品上市资料_结构化整理版.docx`，结果展示摘要与新文件。

### PPT 简化流程

读取 `新品发布会提纲.docx` 并使用 `先马汇报模板.pptx`，经单次内容授权后生成 `新品发布会方案.pptx`，结果展示页数、页面提纲和新文件。

## 四、演示入口与口令

| 场景 | 参数 | 结果 |
| --- | --- | --- |
| Excel 正常 | `scenario=file-excel` | 完整计划、执行、校验与结果 |
| Word 简版 | `scenario=file-word` | 内容授权与结构化 Word |
| PPT 简版 | `scenario=file-ppt` | 内容授权与 PPT 结果 |
| 部分成功 | `scenario=file-partial` | 正常项、异常项和未处理项 |
| 拒绝授权 | `scenario=file-permission-denied` | 取消授权后保持未执行 |
| 文件错误 | `scenario=file-error` | 占用、加密、损坏和字段缺失结果 |

在“新对话”输入 `测试Excel`、`测试Word`、`测试PPT` 可直接进入对应演示流程。所有演示数据均为脱敏占位。

## 五、隐私与异常边界

- 本地工作区授权与模型内容授权分开表达；模型授权展示文件、Sheet/段落、字段范围和用途。
- 拒绝内容授权后不生成文件，不显示上传成功，也不自动降级。
- 默认生成新文件；同名默认保存副本，覆盖必须二次确认。
- 执行详情只展示路径元数据、动作、授权决定、结果和错误，不展示文件正文。
- 支持格式为 `.xlsx`、`.csv`、`.docx`、`.pptx`；旧版 Office、宏和加密文件不进入执行。

## 六、验收重点

- 三种入口是否进入同一任务结构。
- Excel 正常、同名覆盖、部分成功和失败是否均能实际点击演示。
- Word、PPT 是否能完成“计划 → 内容授权 → 结果”的简化闭环。
- 拒绝授权后是否明确未执行且无结果文件。
- 1024px、1280px 下侧栏、输入框和任务卡是否稳定，控制台是否无脚本和缺失图标错误。
