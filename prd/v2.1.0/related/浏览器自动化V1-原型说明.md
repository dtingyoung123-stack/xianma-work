# 浏览器自动化 V1 原型说明

> 状态：浏览器自动页面策略与触发规则、V2.1.0 HTML 原型均已确认，可交开发技术评审与任务拆分；生产实现未核验  
> 更新时间：2026-08-13  
> 需求来源：[[10_先马电商/02_需求与规划/01_需求池/需求档案/2026/REQ-20260811-001_浏览器自动化V1|REQ-20260811-001 浏览器自动化 V1]]

## 1. 原型目标

验证员工直接在普通对话中发起网页任务后，Agent 自动判断是否需要浏览器工具，并自行复用当前页面、匹配页面或打开受控页面，完成“手动登录、动态执行、风险确认、异常恢复、暂停/继续和结果回传”的完整交互。对话是任务入口和状态中心；浏览器页面用于网页执行、登录、查看和员工自行操作，不展示任务侧栏或任务控制。原型只表达已确认的产品行为，不代表底层浏览器能力已经接入或通过开发验收。

## 2. 页面范围

| 页面 | 作用 | 变更方式 |
| --- | --- | --- |
| `应用端/应用端_新对话.html` | 自然语言自动识别浏览器任务；支持输入 `/浏览器` 显式调用；首页通用引导进入新对话并预填命令 | 在现有输入与建议项上增量接入 |
| `应用端/应用端_浏览器任务.html` | 展示新开可控页面的服务工作台演示 | 当前仅覆盖“无可用页面后打开新页面”的降级路径，不代表正式产品固定新开窗口 |
| `应用端/应用端_任务_执行结果.html` | 在原对话中展示动态状态、风险确认、暂停/取消/接管和最终结果 | 浏览器任务的状态与控制中心 |

## 3. 核心流程

```text
普通对话输入网页任务，或使用 /浏览器 显式调用
→ Agent 判断是否需要真实网页 UI；有适合的 API/连接器时优先使用
→ 原对话先显示用户消息和“正在理解任务”状态
→ 需要网页操作时，AI 自动定位当前、匹配或新开的受控页面
→ 指向当前页面时接管当前活动页面；提供网址时优先复用匹配页面
→ 无可用页面时由 AI 自动打开受控页面；目标不明确时才在原对话追问
→ 页面准备后执行；原对话不跳转、不自动切换或抢占浏览器焦点
→ 员工手动登录
→ AI 读取当前页面并动态决定下一动作
→ 页面加载失败时自动重试
→ 提交外部变更前在原对话展示操作摘要
→ 员工在原对话确认或取消
→ 完成后回传网页结果、内容结果或文件结果及确认记录
```

员工在原对话中点击暂停后可自行在浏览器页面操作，暂停按钮切换为继续；也可在对话输入停止或取消结束当前任务。通用任务不预设完整步骤数量，不展示百分比进度，仅在原对话展示当前状态、当前动作和已发生的动态记录。

### 3.1 触发规则

- 判断顺序：绝对禁止项 → 仅网址或仅命令 → 目标是否明确 → 只导航/只读/执行任务；命中前一项后不再进入后续分支。
- 最低执行条件：目标页面可定位、用户目标明确、操作对象明确。任一条件不满足时先追问，不创建 `taskId`。
- 自动触发：用户目标明确要求打开、访问、登录或操作网页，并包含点击、输入、选择、上传、下载、新增、修改、删除、提交或发布等网页动作。
- 显式触发：用户输入 `/浏览器`，或从输入框的“技能与工具”菜单选择浏览器；选中后以山茶红命令标签显示，必须继续补充任务描述或附件。
- 发送标识：显式调用时，发送后的用户消息继续保留山茶红 `/浏览器` 或 `/技能名` 标签，任务描述使用普通正文；自然语言自动调用时不改写用户原话，仅在 AI 回复中显示已调用 `/浏览器`。
- 仅网址：只发送网址视为上下文，不自动打开或执行，回复“你希望我在这个网站完成什么？”，不得进入已完成状态。
- 仅命令或目标模糊：只发送 `/浏览器` 时提示补充任务描述；页面、目标或对象不明确时先追问。
- 导航与只读：“打开/访问 + 可定位页面”只导航；“总结/读取/查看 + 可定位页面”只读，不扩展为写操作。
- 只读触发：“这个网址是什么”“总结当前页面”可按需读取网页，但不授权点击、填写、提交或其他外部变更。
- 工具选择：读取系统数据等语义任务优先使用已接入的 API/连接器；无法完成或仍需 UI 操作时再调用浏览器。
- 浏览器选择：用户指定 Chrome 等浏览器时优先使用指定且可控制的浏览器；未指定时自动选择当前可用浏览器。指定浏览器不可用时提示连接或更换，不静默切换。
- 页面选择：当前页面指令优先接管当前活动页面；提供网址时优先复用匹配页面；无唯一可用页面时由用户连接、选择或打开新页面。
- 首页引导：展示通用文案“使用浏览器完成网页操作”，点击后打开新对话并默认带入 `/浏览器`，不直接执行具体客服示例。
- 持续调用：新对话、任务执行中、完成、失败和取消后的输入框均使用同一份可用技能与工具清单；`/浏览器` 不因已经调用过而消失。只有同一网站、同一核心目标下的补充细节才并入当前任务；更换网站、改变核心目标或推翻已确认内容时，旧确认立即失效，并在当前对话窗口创建新的 `taskId` 和独立任务卡片，不新开对话、不自动跳转。
- 禁止项：支付、转账、密码/安全设置、权限变更、批量删除和合同确认在创建浏览器任务前直接拒绝，不生成 `taskId`，人工确认也不能解锁。

## 4. 原型状态

| 状态 | 页面表现 | 可用操作 |
| --- | --- | --- |
| 正在定位页面 | 对话说明正在查找可操作的浏览器页面 | 取消任务 |
| 待连接 / 选择 | 未找到唯一可接管页面或指定浏览器不可用 | 连接当前浏览器、选择页面、打开新页面、取消任务 |
| 等待登录 | 对话提示等待登录；浏览器停留在网站登录页 | 查看浏览器、取消任务 |
| 执行中 | 对话展示当前动作与动态记录；浏览器仅呈现目标网页 | 查看浏览器、暂停、接管、取消 |
| 自动重试 | 对话展示失败原因、当前重试次数和恢复结果 | 查看浏览器、暂停、接管、取消 |
| 写入结果核验 | 写操作响应不明确时，重新读取页面并核验目标对象，不直接重复提交 | 查看浏览器、人工确认结果、取消后续操作 |
| 等待确认 | 原对话展示网站、动作、影响对象、关键字段和上传文件 | 取消、确认提交 |
| 人工接管 | 对话标记 AI 已停止；浏览器保留当前页面供用户操作 | 交还 AI、取消 |
| 已完成 | 原对话展示操作结果；有真实下载文件时才展示文件操作 | 查看执行详情、查看浏览器、打开下载文件、在文件夹中显示 |
| 已取消 | 尚未产生外部影响，原对话说明任务已停止 | 重试任务 |
| 部分成功 | 已产生部分外部影响，逐项说明已完成、未完成和需人工处理内容 | 查看详情、按剩余事项重试 |
| 失败 / 状态待确认 | 说明失败位置；无法判断写操作是否成功时不得直接重试 | 查看浏览器、人工确认、重试剩余事项 |

## 5. 原型演示数据

- 目标网站使用虚构的“服务工作台”，不使用真实客户、订单、账号或业务数据。
- 示例任务为新增一条服务记录并下载操作结果文件；操作结果文件与平台执行详情是两个概念。
- 文件名、字段内容和结果数据均为演示占位。
- 保留 `应用端/应用端_浏览器任务.html` 中的完整服务工作台演示，不因首页入口通用化而删除。
- 原型演示快捷口令：直接输入“新增一条服务记录”时，按自然语言自动调用 `/浏览器`，目标固定为虚构服务工作台；用户消息保留原文，AI 回复显示 `/浏览器` 工具调用。
- 快捷口令仅用于原型演示。正式产品若当前对话已提供足够的网站和业务上下文，可结合上下文执行；上下文不足时必须追问目标平台及必要信息，不得默认操作虚构服务工作台或任意真实系统。
- 标准演示命令：`/浏览器 打开 https://service.example.com/records，新增一条服务记录并下载执行结果`。
- 发送标准演示命令后，原对话先显示带 `/浏览器` 标签的用户消息与工具调用引导。当前 HTML 因无法模拟真实浏览器连接，仅演示用户选择“打开新页面”后的服务工作台窗口；正式产品应先执行当前页面接管和网址匹配页复用。登录、自动重试、填写、确认新增和结果回传均在原对话继续展示和操作。

### 5.1 任务结果与执行详情

- 任务结果：网站实际生成或下载的文件、网页新增/修改成功结果、截图等业务产物；只有确实存在文件时才展示“打开下载文件”和“在文件夹中显示”。
- 执行详情：平台对本次任务的可追溯摘要，不默认生成 CSV。内容包括任务编号、时间与耗时、调用方式、目标网站、已发生动作、风险确认、暂停/接管等人工控制、最终结果、文件元数据和异常信息。
- 重试分级：读取、查找、导航和普通页面加载失败最多自动重试 2 次；新增、修改、删除、发送、发布、提交和上传等写操作响应不明确时，必须先查询页面、搜索目标记录或检查状态。确认未成功后才可重试；确认已成功则继续；仍无法判断时暂停并标记“状态待确认”。
- 取消结果：取消只停止后续操作，不承诺回退已经提交到外部系统的内容；若取消前已产生外部影响，任务终态为“部分成功”，不得统一显示为“未提交外部数据”。
- 隐私边界：执行详情不记录密码、验证码、Cookie、Token、完整网页源码或文件正文。员工仅查看自己的任务详情；管理后台仅查看按权限开放的元数据，不读取员工任务正文、提示词或文件内容。

## 6. 后续统一 PRD 必须承接

- 对话内自然语言自动触发与 `/浏览器` 显式触发规则，以及仅网址、只读理解、导航和外部变更的分级授权边界。
- 浏览器作为 Agent 底层工具，不设置独立业务入口；优先接管当前可控页面，无可用页面时再连接、选择或打开新页面。
- 每次动作后基于真实页面状态动态决策，不要求提前拆解任意网站的固定步骤，不展示虚假百分比进度。
- 对话内统一展示“正在打开网页、等待登录、正在操作、等待确认、需要人工接管、已完成/部分完成/失败”等通用状态和任务控制，并可附当前动作。
- 发送后先在原对话展示用户消息和理解状态；接管现有页面时展示绑定结果，新开页面只能由员工在无可用页面时选择，不自动跳转或抢占当前对话焦点。
- 显式 `/技能` 标识在发送消息中保留，自然语言自动调用不改写用户原话；全生命周期斜杠菜单与权限内技能、工具清单保持一致。
- API/连接器优先、浏览器兜底的工具选择原则。
- 任意 HTTP/HTTPS 网址与跨域确认规则。
- 手动登录、本机登录状态和账号隔离规则。
- 读取、点击、输入、选择、上传、下载动作边界。
- 外部数据变更和文件上传的风险确认。
- 暂停、取消、重试、人工接管和继续执行。
- 任务结果、执行详情、授权工作区、日志元数据和隐私边界。
- V1 非范围、高风险禁用项、兼容性边界与验收用例。
- 当前技术口径为 Electron 客户端封装 OpenClaw；PRD 需明确 OpenClaw 浏览器能力、工具拦截、人工确认和安全隔离仍需开发 Spike 验证。

## 7. 当前 HTML 演示边界

- `应用端_任务_执行结果.html` 已在原对话提供接管当前页面、选择页面、打开新页面和取消任务，并承载执行、确认、核验、接管及终态展示。
- `应用端_浏览器任务.html` 仅是用户选择“打开新页面”后的虚构服务工作台演示载体；当前页面和候选页面的真实发现、连接及页面切换能力仍需开发接入 OpenClaw 后验证。
- HTML 已覆盖读取类自动重试和写操作结果核验规则，但当前为静态交互原型，不代表任意网站兼容性、登录态隔离、系统级风险拦截或实际写入幂等已经开发完成。
